## Conventions
- Lowercase, hyphenated file names: `2026-09-15-interview-p03.md`
- Put dates first (`YYYY-MM-DD`) so files sort in order
- Anonymise participants (P01, P02…). No real names or consent forms in the repo
- Link big files (videos, recordings, Figma) instead of committing them
