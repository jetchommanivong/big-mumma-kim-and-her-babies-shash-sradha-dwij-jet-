# Research
Everything we learn about users and the problem space.
- `interviews/`: interview guides, notes, transcripts (anonymise participants: P01, P02…)
- `surveys/`: questions and exported results
- `observations/`: field notes, contextual inquiry
- `competitor-analysis/`: existing products, screenshots, comparisons
- `secondary-research/`: articles, papers, stats
- `synthesis/`: affinity maps, insights, personas, journey maps, empathy maps

Consent forms with real names do **not** go in this repo.
