# Prototypes
One subfolder per fidelity. Name versions clearly, e.g. `v1-onboarding`, `v2-onboarding`.
- `low-fi/`: paper prototypes, wireframes
- `mid-fi/`: clickable greyscale wireframes
- `hi-fi/`: polished mockups and interactive prototypes

If the prototype lives in Figma, add a `links.md` with the URL instead of exporting everything.
